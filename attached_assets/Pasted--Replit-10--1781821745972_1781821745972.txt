
🟦 Задача для Replit — Шаг 10: экран решения сданной задачи
Контекст. Открытие задачи в статусе «На приёмке» сейчас — аккордеон, расталкивающий список, с дисбалансом кнопок. Превратить его в отдельный слой принятия решения за 5 секунд по строгой раскладке. Раздел /tasks; эндпоинты /api/tasks/tree (дерево подзадач) и /api/tasks/ai-check уже есть. Если в прошлом шаге сделан RightPanel — открывать поверх него; иначе — отдельный Sheet/слой, не аккордеон.

Поведение. Тап по сданной задаче открывает слой поверх списка; список не расталкивается; закрытие — крестик/подложка/Esc. Плотное стекло, текст читается, шапка и нижние кнопки закреплены, скроллится только тело.

Порядок блоков (строго сверху вниз):

Вердикт-шапка: бейджи «Срочно» / «Зависла · 1д» / «до 18 июн»; название; строка «Сдал: Имя Фамилия · Роль» (аватар-инициалы) + дата + «ждёт вашего решения N дней». Имя+роль, не голая роль.
Что сделано: 2–3 строки сути + кликабельный файл-результат (не путь /reports/...) + кнопка «ИИ-проверка» (/api/tasks/ai-check).
Соответствие задаче — чек-лист «просили vs сдали»: ✓ зелёная = выполнено, «?» жёлтая = слабо/частично. Позволяет принять не вчитываясь. (новый блок)
Распределение — дерево подзадач из /api/tasks/tree: статус + название + исполнитель (имя); узкое место подсвечено жёлтым с «· узкое место, +Nд».
Хроника — свёрнута по умолчанию в одну строку («Хроника · 4 события», шеврон). Локализация: owner → «Заказчик», owner_reminded → «Заказчик напомнил».
Панель решения (sticky снизу): «Вернуть» и «Принять» равного веса. «Вернуть» — вторичный, подпись «нужна причина», открывает обязательное поле причины + выбор получателя (по умолчанию — исполнитель узкого места). «Принять» — акцентный, подпись «уйдёт в архив», даёт подтверждение/тост.
