Шаг 4 — постановка задачи голосом.
Сначала дай план словами, код после моего «ок». Не ломай: глобус, ленту, чат, голос, экран компании. Миграция безопасная (новые таблицы/поля), seed дополняет, не затирает 14 компаний.
1. Данные.

Таблица people (круг приближённых): id, name, role, email (опц.). Засей: Аня — ассистент; Саша Батов — зам, директор по развитию; Николай — операционка/метрики; Татьяна — юр. проекты; Алексей — юридическая часть; Виктор — безопасность; Никита — новый участник; Даша — ИО коммерческого директора платёжных решений.
Таблица tasks: id, title, description, assigneeId (→ people), linkedPeopleIds (массив, опц.), status ("waiting" ждёт принятия | "accepted" принята | "stuck" встала), createdAt, acceptedAt (nullable), stuckDays.
Засей 3–4 демо-задачи с разными статусами: одна «принята», одна «ждёт принятия», одна «встала 3 дня» — чтобы список не был пустой и показывал идею.

2. Эндпоинты.

POST /api/tasks/draft — принимает свободный текст (надиктованный/набранный), через OpenAI (русский) превращает в {title, assigneeId, linkedPeopleIds, description}. В промпт передавай справочник people, чтобы ИИ сопоставлял имена («Ане» → Аня) и роли. Возвращает черновик, НЕ сохраняет.
POST /api/tasks — сохраняет подтверждённую задачу (status "waiting").
GET /api/tasks — список задач с данными исполнителя.

3. Интерфейс.

В левую навигацию добавь пункт «Задачи». Экран: список задач карточками — заголовок, исполнитель (имя + роль), статус цветным бейджем (ждёт принятия — жёлтый, принята — зелёный, встала — красный + «N дней»), доп. участники.
Кнопка «Новая задача» (на экране Задач и быстрая на главном экране). Открывает композер: поле текста + микрофон (переиспользуй голосовой ввод из чата) → надиктовал/написал → «Оформить» → показывается черновик (заголовок, кому, участники) → «Отправить» сохраняет, «Править» даёт отредактировать.
Всё на русском, стиль как везде, iPad-first.

4. Ключевое: в списке видно, что задача закрыта только когда принята (accepted), а не когда просто отправлена. «Встала N дней» — имитация слежения, без реального фона.
Заказчика по имени нигде не упоминать — он владелец/«заказчик».
Открой экран Задач и композер, покажи скрин. Покажи план.
