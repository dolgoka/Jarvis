Экран «Утренняя лента» — задание для агента
Цель: первый экран, который заказчик видит утром. Заходит → сзади мягко крутится глобус → перед ним стопка карточек-новостей, сначала самые критичные. По каждой может пропустить, убрать или сразу голосом/текстом продиктовать ответ — система превращает это в задачу и отправляет нужному человеку. Карточки кончились — «день разобран».
Принципы: планшет, по-русски, стекло (glass), крупные кнопки (≥44pt), никакого технического жаргона на этом экране — заказчик не технарь.

Роут. Новый экран /morning, пока отдельно (роут / не трогаем). Открывается по ?role=client. Позже сделаем стартовым для клиента — но сначала проверим.
Лента карточек. Источник — новая таблица feed_items (id, businessId, type, severity, title, body, relatedPerson, createdAt, status).

severity: critical / important / info. Сортировка строго: критичные → важные → инфо.
type: task_stuck (задача застряла), staff (нанят/уволен ключевой сотрудник), red_zone (компания в красной зоне), routine (день рождения, праздник).
Цвет метки: critical — красный, important — жёлтый, info — нейтральный. Пульс-анимация только на красных.


Карточка. Заголовок, компания, короткое описание, метка важности. Внизу три действия: «Далее», «Убрать», и поле ответа по центру с кнопкой-микрофоном.
Голос/текст → задача.

Микрофон — через webkitSpeechRecognition (распознавание в браузере). Рядом всегда текстовое поле, чтобы можно было проверить скриншотом.
На отправку: POST /feed/draft-task с текстом → OpenAI возвращает черновик: { assignee, action, companyId, watchers[] }. Имя исполнителя — из новой таблицы people (ближний круг).
Показываем черновик карточкой: «Кому: Аня · Что: … · Компания: … · Подключить: …». Кнопки «Отправить» / «Изменить».
«Отправить» → POST /tasks (заглушка, пишем в таблицу tasks) → тост «Отправлено: Аня», карточка помечается разобранной, переход к следующей.


Счётчик и финал. Сверху «осталось N». Когда лента пуста — экран «Лента разобрана на сегодня».
Сиды.

people: Аня (Анна Солонская), Александр Батов, Николай, Татьяна, Алексей, Виктор, Никита, Даша, Дима, Кузя, Андрей Карелин.
feed_items: 6–8 примеров по демо-компаниям (Профимонстерс, Адвокатура, Дальстрой, Аксиома) — минимум 2 critical, 2 important, пара info.



Не делаем в этом заходе: реальную отправку в телеграм/трекер, теги, отметку «задача принята», авто-генерацию красных зон. Только поток «увидел → продиктовал → подтвердил → ушло».
